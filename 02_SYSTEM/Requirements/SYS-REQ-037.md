# SYS-REQ-037 — Capability-Based Mission Planning

## Requirement

Система должна формировать план миссии на основе требуемых capabilities, а не только на основе конкретной модели .

ланирование должно обеспечивать сопоставление:

Task → Capability → UAV → Payload → Algorithm → Mission Plan.

Система должна учитывать зрелость и доступность capability при выборе решения.
