# SYS-REQ-070 — Interface Versioning

## Requirement

нтерфейсы HUB должны поддерживать версионирование.

зменение интерфейса должно быть обратно совместимым в течение установленного переходного периода либо сопровождаться контролируемой миграцией.

ерсия схемы сообщения должна передаваться в составе сообщения.

зменение версии интерфейса не должно нарушать работу совместимых модулей.
