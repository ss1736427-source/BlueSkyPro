# SYS-REQ-013 — Adaptive Autonomy

## Requirement

Система должна задавать автономность по отдельным действиям в соответствии с политикой миссии.

олжны поддерживаться режимы:

- Autonomous;
- Approval Required;
- Human Intervention Required.

римеры:

- Search / Navigation / Tracking — Autonomous;
- Mission replanning — Autonomous;
- ход в новую воздушную зону — Approval Required;
- Mission abort — Human;
- Critical event — Human Intervention.
