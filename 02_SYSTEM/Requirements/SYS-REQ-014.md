# SYS-REQ-014 — Explainable Autonomy

## Requirement

аждое существенное решение AI должно быть объяснимым.

Система должна предоставлять:

- причину решения;
- выбранное действие;
- рассмотренные альтернативы;
- влияние решения на миссию.
