# SYS-REQ-006 — Mission Objective and Optimization Profile Selection

## Requirement

Система должна автоматически определять основной профиль оптимизации миссии на основании поставленной пользователем задачи, требуемого результата, условий выполнения, ограничений и контекста операции.

ользователь не обязан самостоятельно выбирать профиль оптимизации.

Система должна анализировать сформированную задачу и определять, какой из следующих профилей наиболее соответствует цели операции:

- FAST;
- SAFE;
- ECONOMIC;
- HIGH QUALITY.

ыбранный профиль должен использоваться последующими модулями при формировании, оценке и выборе варианта миссии.

## Optimization Profiles

### FAST

рофиль применяется, когда основным критерием является минимизация времени выполнения задачи при соблюдении обязательных требований безопасности и ограничений миссии.

### SAFE

рофиль применяется, когда основным критерием является максимальное снижение операционного риска при достижении требуемого результата.

### ECONOMIC

рофиль применяется, когда основным критерием является экономическая эффективность выполнения миссии и рациональное использование доступных ресурсов.

### HIGH QUALITY

рофиль применяется, когда основным критерием является максимальное качество, полнота или точность результата выполнения задачи.

## Automatic Profile Selection

Система должна определять профиль на основании, в частности:

- цели пользователя;
- требуемого результата;
- срочности;
- требований к качеству результата;
- эксплуатационных ограничений;
- условий выполнения;
- доступных ресурсов;
- требований безопасности;
- характеристик объекта;
- характеристик территории;
- иных существенных параметров сформированной задачи.

ыбор профиля должен выполняться после понимания задачи и до формирования окончательного варианта миссии.

Целевой поток:

CLIENT INTENT
→ TASK UNDERSTANDING
→ MISSION CONFIGURATION
→ TASK CHARACTERISTICS
→ OPTIMIZATION PROFILE SELECTION
→ MISSION AI
→ MISSION VARIANT
→ VALIDATION / SIMULATION
→ APPROVAL
→ EXECUTION

## Profile Selection Result

езультатом работы функции должен быть структурированный объект профиля оптимизации, содержащий:

- выбранный профиль;
- основания выбора;
- существенные факторы, повлиявшие на выбор;
- ограничения, которые должны соблюдаться независимо от профиля;
- параметры, которые должны использоваться Mission AI при формировании миссии.

## Explainable Profile Selection

Система должна объяснять оператору причину выбора профиля.

бъяснение должно показывать:

- какой профиль выбран;
- какие характеристики задачи повлияли на выбор;
- какие требования пользователя были учтены;
- какие ограничения повлияли на решение.

апример:

"ыбран SAFE, поскольку для данной задачи приоритетом является минимизация операционного риска."

бъяснение должно быть доступно оператору до утверждения миссии.

## Operator Control

Система должна предоставлять оператору возможность:

- подтвердить автоматически выбранный профиль;
- изменить выбранный профиль;
- просмотреть основания автоматического выбора;
- вернуть автоматический выбор системы.

зменение профиля оператором должно быть явно зафиксировано в контексте формирования миссии.

зменение профиля не должно отменять обязательные требования безопасности, нормативные ограничения или иные ограничения, которые должны соблюдаться независимо от выбранного профиля.

## Mission Variants

ри необходимости система может сформировать несколько вариантов миссии с различными профилями оптимизации для последующего сравнения.

Сравнение вариантов должно позволять оператору видеть влияние выбранного профиля на характеристики миссии.

## Adaptation

ри изменении исходной задачи, требований пользователя, условий выполнения или существенных ограничений система должна иметь возможность повторно определить профиль оптимизации.

зменение автоматически выбранного профиля должно быть трассируемо до изменившихся факторов задачи.

## Constraints

SYS-REQ-006 не определяет:

- окончательный маршрут;
- окончательный состав флота;
- окончательный выбор ;
- окончательный уровень автономности;
- окончательное решение Safety Engine;
- разрешение на выполнение реальной миссии.

рофиль оптимизации определяет приоритет формирования и оценки миссии, но не отменяет обязательные требования безопасности и ограничения системы.
