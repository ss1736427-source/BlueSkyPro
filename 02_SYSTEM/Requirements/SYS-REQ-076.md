# SYS-REQ-076 — UAV Capability Profile

## Requirement

аждый подключённый  должен иметь машиночитаемый профиль возможностей и ограничений.

рофиль должен учитывать как минимум:
- platform_type
- payload_capabilities
- endurance
- range
- speed
- altitude_limits
- navigation_capabilities
- communication_capabilities
- sensing_capabilities
- landing_capabilities
- current_energy
- current_health
- current_mission_load
