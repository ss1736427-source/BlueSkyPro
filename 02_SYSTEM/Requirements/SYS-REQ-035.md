# SYS-REQ-035 — Task to Capability Mapping

## Requirement

Система должна преобразовывать поставленную задачу в набор необходимых capabilities.

ля каждой задачи должны определяться:

- тип задачи;
- необходимые capabilities;
- типы подходящих ;
- необходимая полезная нагрузка;
- основные алгоритмы;
- требуемая автономность;
- требования к связи;
- критерии успешного выполнения.

римеры задач:

- картография;
- инспекция ;
- инспекция трубопроводов;
- мониторинг территории;
- поиск человека;
- пожары;
- доставка;
- Drone-in-a-box;
- BVLOS мониторинг;
- несколько ;
- обнаружение объектов;
- 3D-реконструкция;
- ретрансляция связи;
- экологический мониторинг;
- C-UAS.
