# SYS-REQ-038 — Multi-UAV Capability Composition

## Requirement

Система должна обеспечивать объединение capabilities нескольких  для решения одной задачи.

азличные  могут выполнять различные функции одной миссии.

апример:

- один  выполняет поиск;
- второй выполняет подтверждение;
- третий обеспечивает ретрансляцию связи;
- четвёртый находится в резерве.

Система должна определять состав группы, распределять capabilities и обеспечивать координацию их совместной работы.

ешение задачи должно оцениваться на уровне всей группы .

## Verification

роверка должна включать миссию, в которой для достижения результата используются минимум два  с различными capabilities.
