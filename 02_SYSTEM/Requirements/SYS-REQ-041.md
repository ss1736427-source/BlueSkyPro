# SYS-REQ-041 — втоматическое формирование рекомендаций

## Requirement

Система должна самостоятельно формировать рекомендации по повышению эффективности, качества и безопасности своей работы на основании результатов анализа накопленных данных.

екомендации могут относиться к:

- алгоритмам;
- параметрам алгоритмов;
- планированию;
- маршрутизации;
- распределению задач;
- выбору ;
- выбору payload;
- использованию ресурсов;
- связи;
- вычислительной нагрузке;
- уровню автономности;
- Mission AI;
- Fleet Orchestration;
- пользовательскому интерфейсу;
- конфигурации системы.

аждая рекомендация должна содержать:

- выявленную проблему;
- причину или предполагаемую причину;
- предлагаемый путь решения;
- ожидаемый эффект;
- возможные риски;
- затронутые компоненты;
- необходимые проверки.

## Principle

Система должна не только сообщать о проблеме, но и предлагать возможные пути её решения.

## Output

ANALYSIS → RECOMMENDATION → EXPECTED IMPROVEMENT
