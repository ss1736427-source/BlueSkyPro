# SYS-REQ-094 — Data Quality for Learning

## Requirement

анные, используемые для анализа, обучения и поиска улучшений, должны проходить контролируемую проверку качества.

олжны учитываться как минимум полнота, согласованность, достоверность, временная целостность, надёжность источника, дублирование и аномальные значения.

екачественные данные не должны автоматически становиться основанием для изменения критического поведения системы.
