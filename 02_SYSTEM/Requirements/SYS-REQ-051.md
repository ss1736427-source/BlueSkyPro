# SYS-REQ-051 — роверка страхового полиса

## Requirement

Система должна проверять действующий страховой полис перед допуском миссии, если страхование является обязательным для конкретной операции.

роверяются:

- номер полиса;
- страховщик;
- страхователь;
- застрахованное лицо/объект;
- С;
- учетный или регистрационный номер;
- страховая сумма;
- покрываемый вид ответственности;
- территория;
- срок действия;
- соответствие требованиям конкретной операции.
