# SYS-REQ-022 — Mission-as-Code и Mission API

## Requirement

Система должна представлять миссию как машиночитаемый объект.

иссия должна поддерживать:

- сохранение;
- клонирование;
- версионирование;
- сравнение;
- запуск по расписанию;
- передачу через API.

одель миссии должна поддерживать операции:

- TASK;
- SCHEDULE;
- DETECT;
- TRACK;
- ESCALATE;
- PAYLOAD;
- OPERATION;
- HUMAN_APPROVAL.
