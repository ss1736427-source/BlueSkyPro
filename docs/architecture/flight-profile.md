# Профиль миссии

## Назначение
Панель «Профиль миссии» отображает и позволяет корректировать вертикальный профиль рассчитанной миссии для выбранного БПЛА. Включение функции добавляет кнопку на левую панель; выключение убирает кнопку и связанные с ней элементы интерфейса.

## Размещение и поведение окна
- Кнопка «Профиль миссии» находится на левой панели.
- По нажатию открывается адаптивное окно в области карты.
- Окно подстраивается под содержимое; пользователь может менять его размеры.
- Вертикальный масштаб профиля регулируется отдельно в пределах окна.
- Окно не должно перекрывать обязательные элементы управления и должно корректно работать при изменении размера основного окна.

## Состав окна
1. Таблица параметров полёта с возможностью корректировать высоту.
2. Вертикальный профиль рассчитанной миссии для выбранного аппарата.
3. Отображение рельефа вдоль маршрута.
4. Отображение опасных превышений/конфликтов высоты на маршруте.
5. Редактируемые точки маршрута.

## Несколько БПЛА
Если в миссии выбрано несколько аппаратов, для каждого показываются собственные расчётные параметры и отдельный вертикальный профиль. Переключение/выбор аппарата должно однозначно связывать таблицу, профиль и редактируемые точки с этим аппаратом.

## Редактирование
- Оператор может вручную изменять высоту точки маршрута перетаскиванием точки по вертикали.
- Изменение высоты синхронно обновляет таблицу и профиль соответствующего аппарата.
- Изменения проходят проверки ограничений высоты, рельефа и опасных зон.
- UI не должен самостоятельно объявлять маршрут безопасным: окончательная валидация выполняется планировщиком/подсистемой безопасности.

## Состояния и ограничения
- Нет выбранного БПЛА: показать нейтральное состояние с предложением выбрать аппарат.
- Нет рассчитанного профиля: показать состояние «Профиль не рассчитан» и доступное действие пересчёта, если оно предусмотрено.
- Ошибка/конфликт ограничений: явно отметить участок и причину; не скрывать предупреждение.
- Скрытие функции убирает кнопку и связанные элементы, не оставляя осиротевших подписей или данных на левой панели.

## Архитектурное разделение
- HMI отвечает за отображение, ввод и передачу пользовательских изменений.
- Планировщик рассчитывает профиль и параметры маршрута.
- Подсистема безопасности/валидации проверяет высоты, рельеф, ограничения и опасные зоны.
- Данные и расчёты ведутся отдельно для каждого выбранного БПЛА.
- UI-прототип не заменяет расчётную и safety-логику.

## Критерии приёмки HMI
- Кнопка появляется только при включённой настройке «Профиль миссии».
- Нажатие открывает окно в области карты; повторное действие закрывает его либо переводит в предусмотренное состояние.
- Окно и вертикальный масштаб можно изменять.
- Таблица и профиль синхронизированы.
- Для каждого выбранного БПЛА отображаются его собственные данные.
- Рельеф, опасные превышения и редактируемые точки визуально различимы.
- Скрытие функции не оставляет лишних элементов на панели.
