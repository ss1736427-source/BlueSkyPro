# BlueSky PRO — эталон настроек карты, сборка № 3

**Назначение:** сохранить параметры удачной карты из архива `BlueSkyPRO-Windows-Map-Review.zip` (версия № 3), чтобы будущие изменения можно было отменить и восстановить настройки вручную.

Этот документ фиксирует настройки, извлечённые из `BlueSky/PRO/qml/MapTilerWebMap.qml` архива № 3. Он не заменяет полный ZIP-архив и не является резервной копией исполняемого файла.

## Основные параметры

- **Картографический движок:** MapLibre GL JS `6.14.0`.
- **Загрузка HTML:** `loadHtml(root.buildHtml(), "https://unpkg.com/")`. CDN-origin используется для совместимости загрузки worker в Qt WebEngine.
- **CSS и ES module MapLibre:** `https://unpkg.com/maplibre-gl@6.14.0/dist/maplibre-gl.css` и `https://unpkg.com/maplibre-gl@6.14.0/dist/maplibre-gl.mjs`.
- **Стиль по умолчанию:** MapTiler `hybrid-v4`.
- **Доступные стили:** `hybrid-v4`, `satellite-v4`, `streets-v4`.
- **Начальный центр:** longitude `31.95990`, latitude `49.85842`.
- **Начальный масштаб:** `6.7`.
- **Подписи:** включены по умолчанию; кнопка позволяет отключать и включать их.
- **3D-рельеф:** выключен по умолчанию; при включении используется MapTiler `terrain-rgb-v2`, `tileSize: 256`, `exaggeration: 1.0`, наклон камеры `55°).
- **Переключение стиля:** полный сброс стиля через `map.setStyle(url, {diff:false})`; не заменять на diff-update без отдельной проверки.
- **Кэш тайлов:** `maxTileCacheZoomLevels: 6`.
- **Поведение загрузки:** `fadeDuration: 0`, `refreshExpiredTiles: false`, `cancelPendingTileRequestsWhileZooming: true`, `crossSourceCollisions: false`.
- **Камера:** `maxPitch: 60).
- **Canvas:** `antialias: false`, `preserveDrawingBuffer: false).
- **Фон WebEngine и карты:** `#071321).
- **Атрибуция:** `attributionControl: true).

## Ключ API

Ключ не хранить в Git и не записывать в этот документ. Приложение ожидает переменную окружения `BLUESKY_MAPTILER_API_KEY`. Если она не задана, карта показывает сообщение об отсутствии ключа.

## Интеграция маршрута

- Qt-свойство `routeCoordinates` передаёт точки маршрута; источник данных маршрута создаётся как GeoJSON только при необходимости.
- Для обновления используется `setData` существующего источника, если он уже создан.
- Идентификаторы слоёв: `bluesky-route-line` и `bluesky-route-points).
- Планировщик (Planning Core) остаётся единственным источником геометрии маршрута; пустой массив означает отсутствие наложения маршрута.

## Правило дальнейших изменений

Считать этот документ контрольной записью параметров версии № 3. Не менять параметры эталона как часть обычной доработки. Перед изменениями карты сначала сохранить текущий рабочий результат; при регрессии восстановить исходный QML из архива № 3 и сверить контрольную сумму.

Полный архив сборки хранится отдельно от Git, поскольку он превышает ограничение GitHub для одного файла в обычном репозитории.
