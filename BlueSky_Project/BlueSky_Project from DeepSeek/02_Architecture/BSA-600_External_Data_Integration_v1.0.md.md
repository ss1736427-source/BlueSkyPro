## 1. Назначение

Документ определяет **выбранные внешние источники данных** для системы BlueSky Flight Planning, правила их использования и архитектуру интеграции.

Все решения в настоящем документе являются **утвержденными** и обязательными для реализации.

## 3. Погодные данные
### 3.1. Выбранный источник
| Параметр | Значение |
| :--- | :--- |
| **Источник** | Aviation Weather Center (AWC) / NOAA / NWS |
| **URL** | `https://aviationweather.gov/api/data/` |
| **Доступ** | ✅ **Публичный, API-ключ НЕ ТРЕБУЕТСЯ** |
| **Лимит** | ⚠️ **100 запросов в минуту** на IP-адрес |
| **Форматы** | JSON, GeoJSON, XML, IWXXM, CSV |
| **Глубина истории** | До 15 дней |
### 3.2. Доступные продукты AWC
| Продукт | Описание | Покрытие |
| :--- | :--- | :--- |
| **METAR** | Текущие метеонаблюдения на аэродромах | Глобальное |
| **TAF** | Терминальные прогнозы погоды | Глобальное |
| **SIGMET** | Значительные метеоявления (опасные) | Глобальное |
| **AIRMET** | Метеоявления для малых ВС | США |
| **G-AIRMET** | Графические AIRMET | США |
| **PIREP** | Доклады пилотов | США / Северная Атлантика |
| **WINTEM** | Прогноз ветра и температуры по маршруту | Глобальное |
### 3.3. Пример запроса (без ключа)

```python
import requests
# Получение METAR для аэропорта Шереметьево (UUEE)
response = requests.get(
    "https://aviationweather.gov/api/data/metar",
    params={
        "ids": "UUEE",
        "format": "json"
    }
)
data = response.json()

### 3.4. Резервный источник

|Параметр|Значение|
|---|---|
|**Источник**|OpenWeatherMap|
|**Доступ**|API-ключ (бесплатный, 1000 запросов/день)|
|**Применение**|Резерв при недоступности AWC|

## 4. NOTAM (Уведомления об ограничениях)

### 4.1. Выбранные источники

|Источник|Покрытие|Доступ|Статус|
|---|---|---|---|
|**FAA NOTAM API**|США|**Требуется API-ключ** (регистрация на портале FAA)|Основной|
|**Aviation Edge NOTAM API**|Международное|**Требуется API-ключ** (коммерческий тариф)|Дополнительный|

### 4.2. Стратегия получения ключей

|Действие|Кто выполняет|Срок|
|---|---|---|
|Регистрация на **FAA External API Portal**|Проектная группа|При переходе в фазу разработки|
|Получение **Client ID** и **Secret**|FAA|После регистрации|
|Тестирование интеграции|Разработчики|После получения ключей|

## 5. Расписание обновления данных

|Данные|Источник|Интервал обновления|Приоритет|
|---|---|---|---|
|**METAR**|AWC|Каждые 5–10 минут|1 (критические)|
|**TAF**|AWC|Каждые 6 часов|2|
|**SIGMET**|AWC|По факту выпуска|1 (критические)|
|**AIRMET**|AWC|По факту выпуска|2|
|**PIREP**|AWC|По факту поступления|3|
|**NOTAM**|FAA / Aviation Edge|По запросу / периодически|1 (критические)|

---

## 6. Очереди приоритетов (DUM)

|Приоритет|Тип данных|Период обновления|
|---|---|---|
|**1 (Высший)**|Критические события безопасности (SIGMET, NOTAM)|Мгновенно, по факту|
|**2**|Телеметрия и состояние связи|1 сек|
|**3**|NOTAM|5 мин|
|**4**|Ограничения воздушного пространства|5 мин|
|**5**|Погода (METAR, TAF)|5–10 мин|
|**6**|Разрешения и уведомления|15 мин|
|**7**|Аналитика и отчеты|1 час|

---

## 7. Ограничения и их обработка

|Ограничение|Источник|Способ обработки|
|---|---|---|
|**100 запросов/мин**|AWC|Интеллектуальное кеширование, интервалы обновления|
|**400 записей/ответ**|AWC|Пагинация, фильтрация по геозоне|
|**Требуется ключ**|FAA NOTAM API|Регистрация на портале FAA|
|**Требуется ключ**|Aviation Edge|Коммерческий тариф (при необходимости)|
|**Глубина 15 дней**|AWC|Использовать для оперативного планирования, историю хранить в TimescaleDB|

---

## 8. Хранение данных

|Данные|Хранилище|Примечание|
|---|---|---|
|**Погодные данные**|PostgreSQL (PostGIS) + TimescaleDB|TimescaleDB — для временных рядов|
|**NOTAM**|PostgreSQL (PostGIS)|Геопространственные индексы|
|**История погоды**|TimescaleDB|Для анализа и обучения AI|
|**Кеш данных**|Redis (опционально)|Для ускорения доступа|
