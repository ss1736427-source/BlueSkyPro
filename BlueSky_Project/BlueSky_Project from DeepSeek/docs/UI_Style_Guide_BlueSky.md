# BlueSky Flight Planning
## UI Style Guide v1.0

---

## 1. ШРИФТЫ

| Параметр | Значение |
| :--- | :--- |
| **Основной шрифт** | **Inter** |
| Веса | Regular (400), Medium (500), SemiBold (600), Bold (700) |

### Размеры текста

| Элемент | Размер | Применение |
| :--- | :--- | :--- |
| Большие показатели | 28–34 px | Высота, скорость, время, ETA |
| Заголовки | 18–20 px | MISSION ANALYSIS, MISSION TEMPLATES |
| Подзаголовки | 15–16 px | Mission Parameters |
| Основной текст | 13–14 px | Значения параметров, waypoints |
| Подписи | 11–12 px | REG, RDY, ETD, ETA, метки статуса |
| Мелкие подписи | 10 px | Второстепенные метки |

## 2. ЦВЕТОВАЯ ПАЛИТРА

### Основной фон

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Основной фон | `#0E1726` | Главный фон экрана |
| Панели | `#162338` | Боковые панели, карточки |
| Вторичный фон | `#1B2A42` | Активные элементы |

### Синий (главный акцент)

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Primary Blue | `#2D8CFF` | Кнопки, активные элементы |
| Hover Blue | `#3EA0FF` | Наведение |
| Light Blue | `#6FC4FF` | Подсветка, акценты |

### Зеленый

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Green | `#27D05E` | Статус "Готов", OK |
| Success | `#36C96F` | Успешное выполнение |

### Желтый

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Yellow | `#F4C542` | Предупреждения, NOTAM |

### Красный

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Red | `#D84A4A` | Зоны ограничений |
| Danger | `#E53935` | Кнопка Abort, ошибки |

### Бирюзовый

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Turquoise | `#33D0FF` | Маршрут на карте |

### Текст

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Text | `#FFFFFF` | Основной текст |
| Secondary Text | `#D6E2F2` | Второстепенный текст |
| Muted | `#A6B6CC` | Подписи, метки |

### Границы

| Назначение | HEX | Применение |
| :--- | :--- | :--- |
| Border | `#2A3B56` | Рамки панелей |

## 3. КОМПОНЕНТЫ

### Кнопки

| Тип | Background | Text | Применение |
| :--- | :--- | :--- | :--- |
