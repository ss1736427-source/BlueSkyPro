# BlueSky Flight Planning
## BSA-101 Navigation Engine Architecture

---

## 1. Назначение

**Navigation Engine** — это навигационное ядро системы BlueSky. Оно выполняет:

- Построение и оптимизацию маршрутов
- Проверку и валидацию миссии
- Учет рельефа, препятствий и ветра
- Обход зон ограничений и NOTAM
- Расчет магнитного курса (МК) с учетом склонения
- Построение профиля высоты
- Расчет ETA и энергопрогноза

---

## 2. Входные данные

| Категория | Данные | Источник |
| :--- | :--- | :--- |
| **Миссия** | Координаты старта (S) и финиша (END) | Mission Engine |
| **Миссия** | Обязательные точки (waypoints) | Mission Engine / Пользователь |
| **Миссия** | Профиль миссии (энергия, время, безопасность) | Mission Engine |
| **БПЛА** | Тип БПЛА, характеристики | Configuration Manager |
| **БПЛА** | Полезная нагрузка, масса | Configuration Manager |
| **БПЛА** | Максимальная высота, скорость | Configuration Manager |
| **Ограничения** | NOTAM, запретные зоны, CTR, TMA, FIR | Regulatory Engine / DUM |
| **Погода** | Ветер по высотам, температура, давление | Weather Engine / DUM |
| **Рельеф** | Высоты местности, SRTM / ASTER GDEM | Внешние картографические сервисы |
| **Препятствия** | Здания, вышки, ЛЭП, деревья, краны | Картографические сервисы / Пользователь |

---

## 3. Выходные данные

| Данные | Описание |
| :--- | :--- |
| **Маршрут** | Последовательность waypoints (координаты, высота, скорость) |
| **Профиль высоты** | График высоты по маршруту |
| **Магнитный курс (МК)** | Курс в каждой точке маршрута |
| **ETA** | Расчетное время прибытия |
| **Расход энергии** | Прогноз потребления энергии по участкам |
| **Альтернативы** | Запасные маршруты (2-3 варианта) |
| **Индекс готовности миссии** | Оценка безопасности и выполнимости |

## 5. Алгоритмы

### 5.1. Гибридный A* (Основной поиск пути)

| Параметр | Значение |
| :--- | :--- |
| **Назначение** | Поиск кратчайшего пути на сетке с учетом препятствий и весов |
| **Эвристика** | Евклидово расстояние (сферическое) |
| **Весовая функция** | F = G + H + W, где W — учет ветра, высоты, зон ограничений |
| **Сетка** | Адаптивное разрешение (мелкая у препятствий, крупная на открытой местности) |

### 5.2. TIG* (3D-обход препятствий)

| Параметр | Значение |
| :--- | :--- |
| **Назначение** | Обход препятствий сложной формы в 3D-пространстве |
| **Применение** | Горная местность, городская застройка |
| **Результат** | Плавный обход с учетом рельефа |

### 5.3. Catmull-Rom Сплайны (Сглаживание)

| Параметр | Значение |
| :--- | :--- |
| **Назначение** | Сглаживание ломаного пути в плавную кривую |
| **Особенность** | Проходит через все waypoints |

## 6. Расчет магнитного курса (МК)

### 6.1. Определение

> **Магнитный курс (МК)** — угол, измеряемый по часовой стрелке от северного направления истинного меридиана (указанного на карте полетов с учетом склонения) до линии заданного пути (ЛЗП).

### 6.2. Формула
МК = Направление ЛЗП ± ΔM

Где:
- **ΔM** — магнитное склонение (берется с карты полетов)
- **Восточное склонение (E)** — ΔM > 0 → **вычитаем**
- **Западное склонение (W)** — ΔM < 0 → **прибавляем**

### 6.3. Пример

| Параметр | Значение |
| :--- | :--- |
| Направление ЛЗП | 85° |
| Магнитное склонение | 8°E (восточное) |
| **МК = 85° − 8° = 77°** | |

### 6.4. Отображение на карте

| Элемент | Цвет |
| :--- | :--- |
| **Магнитный курс (МК)** | 🟢 Зеленый |
| **Магнитное склонение (ΔM)** | 🔴 Красный |

### 7.2. Отображение на карте

| Высота | Цвет |
| :--- | :--- |
| 0–50 м | 🔵 Синий |
| 50–100 м | 🟢 Зеленый |
| 100–200 м | 🟡 Желтый |
| 200–500 м | 🟠 Оранжевый |
| > 500 м | 🔴 Красный |

## 8. Учет препятствий

### 8.1. Типы препятствий

| Тип | Радиус безопасности (вертикаль) | Радиус безопасности (горизонталь) |
| :--- | :--- | :--- |
| Здание | +20 м | +50 м |
| Вышка | +30 м | +100 м |
| ЛЭП | +10 м | +50 м |
| Кран | +20 м | +50 м |
| Дерево | +5 м | +20 м |
| Труба | +20 м | +50 м |

### 8.2. Правила обхода

1. Препятствия с высотой > 50 м требуют обхода
2. Обход по высоте — увеличение высоты на безопасный интервал
3. Обход боковым уклонением — смещение маршрута на безопасное расстояние

## 10. Расчет ETA

### 10.1. Формула
ETA = Старт + Σ (S_i / W_i)

Где:
- **S_i** — длина i-го участка
- **W_i** — путевая скорость на i-м участке

### 10.2. Учет факторов

| Фактор | Влияние на ETA |
| :--- | :--- |
| Ветер | Попутный → уменьшение времени; Встречный → увеличение |
| Высота | Набор → увеличение времени; Снижение → уменьшение |
| Рельеф | Подъем → увеличение; Спуск → уменьшение |
| Профиль миссии | Максимальная энергия → выше время; Минимальное время → ниже время |
