# BlueSky PRO — Mission Time Model 001

## 1. Назначение

Фиксирует согласованную логику времени миссии для верхней панели, панели БПЛА и расчёта продолжительности/возврата.

## 2. Общие правила

- Все расчёты и операции используют **UTC**.
- Точность отображения времени: **ЧЧ:ММ**.
- Плановое и фактическое время разделяются.
- Временные параметры конкретного БПЛА рассчитываются индивидуально.
- Верхняя панель отображает сводное состояние всей миссии.

## 3. ETD — плановое время вылета

### 3.1 Миссия по расписанию

Для работ по расписанию доставки, например А → В, плановое время из расписания автоматически устанавливается в ETD.

### 3.2 Миссия без расписания

Для иных работ ETD формируется автоматически:

```text
ETD = время входа в систему + время подготовки к полёту
```

Базовое время подготовки — **15 минут**.

Система может корректировать базовое время подготовки на основании статистики фактического времени подготовки. Система только **предлагает** коррекцию; изменение базового времени требует обязательного подтверждения оператора.

Пилот также может вручную изменить ETD конкретного рейса через клик по области ETD и подтверждение коррекции.

### 3.3 ЕСОРВД

При автоматической подаче плана полёта в ЕСОРВД время в плане устанавливается по ETD, назначенному и проверенному пилотом.

### 3.4 CNL

При отмене полёта с подачей CNL:

```text
ETD = --
```

Если пилот остаётся в текущей сессии, новое время вылета назначается им вручную.

Правило `CNL → ETD = --` не переносится на новую сессию после выхода из системы и нового входа.

### 3.5 Изменение расписания

При изменении расписания система предупреждает пилота и указывает новое время. После подтверждения пилотом ETD корректируется на новое время.

### 3.6 Контроль ETD

- За 1 минуту до ETD, если вылет ещё не начат, ETD отображается жёлтым.
- Со следующей минуты после назначенного ETD, если вылет не совершён, ETD отображается красным.
- При клике по просроченному ETD система показывает задержку в минутах.
- После фактического взлёта цвет ETD возвращается к нормальному.
- После назначения нового времени и подачи плана полёта на новое время цвет ETD также возвращается к нормальному.
- Фактическая задержка взлёта фиксируется в журнале.

## 4. TOT — фактическое время взлёта

TOT не определяется нажатием кнопки START.

TOT фиксируется **по фактическому событию взлёта БПЛА**.

Для групповой миссии:

```text
TOT миссии = фактическое время взлёта первого БПЛА
```

Именно от TOT начинается расчёт фактического времени выполнения групповой миссии.

## 5. TRIP — продолжительность миссии

### 5.1 Групповая миссия

```text
TRIP = от фактического взлёта первого БПЛА
       до посадки последнего БПЛА
```

### 5.2 Один БПЛА

Если аппарат один:

```text
TRIP = от начала движения БПЛА
       до момента касания при посадке
```

Таким образом, для одиночного БПЛА начало TRIP — **начало движения**, а не TOT.

## 6. Предвзлётный расход энергии и время

Для энергетического расчёта учитывается период с начала движения БПЛА, включая предусмотренное время подготовки аккумулятора в режиме висения.

Это время не смешивается с семантикой TOT: TOT остаётся фактическим временем взлёта.

## 7. Запас энергии миссии

Запас энергии миссии рассчитывается с учётом:

1. запаса энергии на начало движения первого БПЛА;
2. запаса энергии до посадки последнего БПЛА;
3. остаточной энергии остальных БПЛА по принципу оценки периода от начала движения каждого аппарата до момента его посадки.

Расчёт должен учитывать фактическое состояние каждого БПЛА и параметры, влияющие на расход энергии.

## 8. Расчёт продолжительности и аварийного возврата

Продолжительность миссии рассчитывается с учётом возможности аварийного возврата.

Для оценки возврата используется фактическое состояние конкретного БПЛА:

```text
Current Navigation State
+
Energy / Resource State
+
Communication State
+
Environment / Wind
+
Mission Constraints
+
Return Route
→ Return Feasibility
```

Расчёт аварийного возврата строится по логике фактического маршрута возврата и энергетической выполнимости, а не только по геометрическому расстоянию.

## 9. DESTINATION

По умолчанию БПЛА возвращается к **оператору / передатчику**, то есть к текущему месту нахождения передатчика.

Если в миссии назначен иной `DESTINATION`, возврат выполняется в назначенную точку.

Это правило применяется и при аварийном возврате.

## 10. ETA

ETA верхней панели относится ко всей миссии:

```text
ETA = расчётное время посадки последнего БПЛА
```

Для одиночной миссии единственный БПЛА является одновременно первым и последним.

ETA рассчитывается на основе фактического состояния БПЛА и текущего расчёта маршрута/возврата.

## 11. Верхняя панель

Верхняя панель отображает сводное состояние миссии:

```text
MISSION STATUS | ETD | TOT | TRIP | ETA
```

При групповой миссии верхние временные показатели рассчитываются из индивидуальных временных данных панели БПЛА с учётом фактического взлёта первого и посадки последнего аппарата.
