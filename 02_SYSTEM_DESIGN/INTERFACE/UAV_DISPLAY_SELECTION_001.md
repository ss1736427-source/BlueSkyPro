# BlueSky PRO — Автоматический подбор инструментов отображения панели БПЛА

## 1. Назначение

Для каждого конкретного БПЛА система автоматически подбирает минимальный необходимый набор инструментов для отображения на его панели.

## 2. Основа подбора

Подбор выполняется с учётом:

- типа выполняемой миссии;
- роли конкретного БПЛА в миссии;
- необходимых для выполнения задачи данных;
- наиболее часто используемых пилотом инструментов.

## 3. Принцип минимализма

Система выводит только необходимый минимум инструментов, чтобы не засорять поле интерфейса избытком информации.

Параметры и инструменты, не являющиеся необходимыми для текущей задачи, не выводятся постоянно.

## 4. Меню выбора отображения

На панели БПЛА предусмотрен инструмент настройки отображения `[⚙]`.

По его нажатию открывается выпадающее меню выбора инструментов для отображения на панели конкретного БПЛА.

Пилот может вручную:

- добавить инструмент на панель;
- убрать инструмент с панели;
- изменить порядок отображения выбранных инструментов.

## 5. Приоритет инструментов

Наиболее часто востребованные инструменты располагаются сверху списка выбора.

Система может автоматически учитывать частоту использования и поднимать наиболее востребованные инструменты вверх списка.

Оборудование, необходимое для разных задач, также учитывается при формировании приоритетного списка.

## 6. Адаптация к миссии

При выборе/изменении типа миссии и роли БПЛА система формирует соответствующий минимальный набор рекомендуемых инструментов.

```text
ТИП МИССИИ
      +
РОЛЬ БПЛА
      +
ЧАСТОТА ИСПОЛЬЗОВАНИЯ
      +
НЕОБХОДИМОЕ ОБОРУДОВАНИЕ
      ↓
МИНИМАЛЬНЫЙ НЕОБХОДИМЫЙ НАБОР
      ↓
ОТОБРАЖЕНИЕ НА ПАНЕЛИ БПЛА
```

## 7. Постоянно отображаемая базовая область A

По умолчанию отображаются:

- квадратное изображение БПЛА;
- название и порядковый номер в одной компактной строке над изображением, например `SKYMASTER № 2`;
- бортовой номер и статус готовности;
- высота;
- скорость;
- Battery в процентах;
- режим работы двигателей — горизонтальный индикатор от минимального до максимального режима, фактический режим обозначается линией по шкале и цифровым значением;
- индикатор миссии в нижней части секции.

Четыре основных параметра (`Высота`, `Скорость`, `Battery`, `Двигатели`) выводятся по умолчанию, но пилот может скрыть любой из них, вернуть скрытый инструмент или изменить их порядок.

Изображение БПЛА автоматически подтягивается из карточки БПЛА/базы конфигурации.

Приоритет источников изображения:

1. индивидуальное изображение конкретного БПЛА;
2. изображение модели БПЛА;
3. нейтральный placeholder при отсутствии изображения.

Изображение хранится локально, чтобы панель сохраняла работоспособность без внешнего подключения.

```text
ADMIN
  ↓
БАЗА БПЛА
  ↓
ИЗОБРАЖЕНИЕ
  ↓
ПАНЕЛЬ БПЛА
```

## 8. Умные инструменты

Дополнительные выбранные инструменты отображаются компактно без постоянной области прокрутки.

Пример:

```text
[Ветер] [Курс] [ETA] [C2] [Камера] [+]
```

По нажатию раскрывается только выбранный инструмент; остальные остаются компактными.

Кнопка `[+]` открывает выпадающее меню выбора инструментов.

## 9. Автоматический подбор отображения

Система автоматически формирует минимальный набор дополнительных инструментов с учётом:

- типа миссии;
- роли БПЛА в миссии;
- необходимого оборудования для текущей задачи;
- частоты использования инструментов.

Автоматический подбор не должен приводить к перегрузке панели.

## 10. Адаптивный размер окна

Окно БПЛА автоматически подстраивается под объём отображаемой в нём информации.

- при небольшом объёме информации окно компактное;
- при добавлении инструментов окно увеличивается по высоте в пределах доступной области;
- после достижения максимальной высоты дополнительная информация не должна растягивать окно бесконечно;
- используется раскрытие отдельных умных инструментов, а не постоянная область прокрутки;
- критически важные параметры не должны становиться недоступными из-за переполнения.

## 11. Завершение миссии

После завершения миссии конкретным БПЛА:

- его окно становится неактивным и визуально серым;
- нижняя линия состояния миссии заменяется сообщением `ЗАВЕРШЕНО`;
- информация в окне сохраняется для идентификации аппарата и контроля результатов.
