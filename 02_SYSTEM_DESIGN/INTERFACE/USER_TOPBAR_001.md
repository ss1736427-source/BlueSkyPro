# BlueSky PRO — USER верхней панели

## Постоянно отображается

- **Фото** пользователя.
- **Имя и Фамилия** пользователя.
- **Роль:** ПИЛОТ.

## Авторизация

Пользователь авторизуется в самом начале при входе в систему по логину и паролю. После успешной авторизации подтверждённая учётная запись автоматически применяется системой там, где требуется идентификация пользователя.

## Карточка пользователя

По клику на область USER открывается скрытое меню/карточка пользователя.

Из карточки пользователь может редактировать свою карточку, включая фото и доступные персональные данные.

## Минимализм

На верхней панели не отображаются дополнительные сведения о пользователе. Они доступны только через клик по области USER.

Роль и идентификация пользователя являются частью постоянно отображаемой области USER.

## Идентификация действий

Действия пользователя в системе маркируются его именем для идентификации действий в журнале.
