# ADMINISTRATOR_ENGINEER_TECHNICIAN_ACCESS_RULE_002

## Зафиксированное правило доступа

Администратор системы назначает пользователю базовые роли. Если пользователю назначены `PILOT`, `TECHNICIAN` и `ENGINEER`, роли совмещаются в одной учётной записи.

### Техническая модель

```text
SYSTEM ADMINISTRATOR
        │
        │ назначает роли
        ▼
     USER
   ┌───┼───┐
   ↓   ↓   ↓
 PILOT TECHNICIAN ENGINEER
             │        │
             │        ├── доступ ко всему парку БПЛА
             │        ├── доступ ко всем техническим данным
             │        ├── инженерная конфигурация
             │        └── определение допусков TECHNICIAN
             │
             └───────────────┐
                             ↓
                   только разрешённая
                   техническая область

ENGINEER → определяет → TECHNICIAN ACCESS
```

## Правила

1. `ENGINEER` имеет полный доступ к техническому парку БПЛА и всем данным, доступным в его техническом контуре.
2. `ENGINEER` определяет технические допуски подчинённых `TECHNICIAN`.
3. Допуск `TECHNICIAN` может ограничиваться конкретным БПЛА, конфигурацией, оборудованием, видом или уровнем технической работы.
4. `TECHNICIAN` видит и выполняет только те технические функции и задачи, которые разрешены ему `ENGINEER`.
5. Наличие роли `TECHNICIAN` само по себе не открывает доступ ко всему техническому парку.
6. `ADMINISTRATOR` не распределяет отдельные технические операции между техниками; он назначает базовые роли и управляет учётными записями.
7. `ENGINEER` является старшим техническим уровнем относительно `TECHNICIAN` в организационной модели BlueSky PRO.
8. `Certification / Release Authority` относится к роли `ENGINEER` как отдельное явно назначаемое полномочие.
9. Персональная настройка меню изменяет отображение доступных функций, но не расширяет полномочия.

## Минимальная модель интерфейса

```text
ADMINISTRATOR
└── USERS
    └── Сергей Иванов
        ├── ☑ PILOT
        ├── ☑ TECHNICIAN
        └── ☑ ENGINEER
```

Дальше система автоматически формирует рабочий контур пользователя.

Для `ENGINEER`:

```text
ENGINEER
├── Весь парк БПЛА
├── Все технические данные
├── Конфигурации
├── Оборудование
└── Допуски персонала
```

Для `TECHNICIAN`:

```text
TECHNICIAN
└── Разрешённая ENGINEER область
    ├── БПЛА
    ├── оборудование
    ├── конфигурации
    └── разрешённые работы
```
