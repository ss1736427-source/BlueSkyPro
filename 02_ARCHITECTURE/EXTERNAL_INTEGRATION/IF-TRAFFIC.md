# IF-TRAFFIC — Traffic Awareness Interface

## Purpose
Define ingestion of external traffic information for situational awareness and safety logic.

## Sources
ADS-B and other approved traffic sources available to the operational environment.

## Data
Track identity where available, position, altitude, velocity, heading, timestamp, quality and source.

## Required behavior
Traffic data must be time-valid, source-labelled and quality-checked before use by safety/awareness functions.

## Key requirement
Traffic awareness is an input to the operational/safety layer, not a replacement for the aircraft's own collision-avoidance or flight-control functions.
