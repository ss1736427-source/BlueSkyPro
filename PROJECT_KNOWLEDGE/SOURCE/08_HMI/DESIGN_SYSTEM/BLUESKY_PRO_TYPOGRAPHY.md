# BlueSky PRO — Typography

## Current project typography

| Role | Font | Weight / use |
|---|---|---|
| Основной UI | Inter | обычный UI-текст |
| Заголовки | Inter Tight | 600 / 700 |
| Telemetry / technical data | B612 / B612 Mono | числовые и технические значения |

## Telemetry examples

`ALTITUDE 1 240 m`  
`SPEED 18.4 m/s`  
`HEADING 274°`  
`BATTERY 82%`

## Rules

- Основной UI-шрифт не смешивать с telemetry font без назначения.
- Числовые значения должны сохранять стабильную ширину и читаемость.
- Размеры текста должны адаптироваться к масштабу интерфейса и карте там, где это предусмотрено требованиями отображения.
- Для панели карты размеры подписей должны быть согласованы с масштабом карты.
- Шрифт логотипа является частью brand asset и не заменяется системным UI-шрифтом.

## Asset requirement

Файлы шрифтов и их лицензии должны быть добавлены в controlled assets после подтверждения комплекта.
