# SYS-REQ-036 — UAV Type and Payload Selection

## Requirement

Система должна выбирать подходящий тип  и полезную нагрузку на основании требований задачи.

ри выборе должны учитываться:

- тип платформы;
- capabilities;
- payload;
- дальность;
- продолжительность полёта;
- энергия;
- связь;
- автономность;
- ограничения эксплуатации;
- требования безопасности.

Система должна поддерживать различные типы платформ, включая multirotor, fixed-wing, VTOL и специализированные системы.

обавление нового типа  или payload не должно требовать изменения общей архитектуры системы.
