# SYS-REQ-101 — Failed Improvement Analysis

## Requirement

сли улучшение не достигло ожидаемого результата или привело к отрицательному эффекту, система должна зарегистрировать событие неудачного улучшения и выполнить анализ причины.

нализ должен рассматривать как минимум:
- неверное предположение
- недостаточность данных
- ошибку модели
- ошибку реализации
- неверную оценку риска
- влияние внешних условий
- непредусмотренное взаимодействие компонентов
- ресурсное ограничение
- ошибку прогнозирования

ричина неудачи должна быть отделена от самого факта неудачи.
