# SYS-REQ-026 — рхитектура пользовательских интерфейсов

## Requirement

Система должна обеспечивать разделение пользовательских функций на три функциональных контура:

### PILOT
Управление отдельным :
- Управление
- олёт
- авигация
- Aircraft
- астройки
- редупреждения
- аршрут
- Состояние
- Связь
- осадка

### HUB
Управление флотом и операциями:
- иссии
- ониторинг
- анные
- оманда
- налитика
- арта
- езопасность
- блако
- Система
- рхив

### PRO
нтеллектуальный слой:
- адачи
- Шаблоны
- Mission AI
- Fleet Orchestration
- Validation
- Simulation
- Autonomy
- Knowledge
- Optimization
- Mission History
