# SYS-REQ-027 — Administration and Technical Management

## Requirement

Система должна иметь отдельный административный контур ADMIN для авторизованного технического персонала.

ADMIN должен обеспечивать управление и просмотр полного набора технических данных и параметров системы.

## Scope

- системная конфигурация;
- конфигурация ;
- hardware;
- firmware;
- software;
- payload;
- sensors;
- capabilities;
- algorithms;
- AI models;
- communication и C2;
- interfaces;
- технические параметры;
- диагностика;
- журналы;
- системные состояния;
- ошибки и предупреждения;
- обновления;
- параметры безопасности.

## Access

ADMIN должен иметь отдельные права доступа и не смешиваться с операционными интерфейсами PILOT, HUB и PRO.
