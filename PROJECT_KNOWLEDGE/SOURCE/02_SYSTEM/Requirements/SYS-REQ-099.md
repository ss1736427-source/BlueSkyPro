# SYS-REQ-099 — Controlled Improvement Deployment

## Requirement

добренное улучшение должно внедряться контролируемым способом.

ля изменения должны фиксироваться версия, идентификатор deployment, исходный baseline и статус внедрения.

сли политика изменения предусматривает rollback, механизм возврата должен быть доступен и проверен.
