# SYS-REQ-028 — Configuration Management

## Requirement

Система должна обеспечивать управление конфигурацией компонентов и технических параметров.

олжны поддерживаться:

- configuration items;
- версии;
- baseline;
- изменения;
- история изменений;
- статус конфигурации;
- связь конфигурации с конкретной системой,  и программным обеспечением.

## Traceability

онфигурация должна быть связана с соответствующими требованиями, версиями , алгоритмами и результатами верификации.
