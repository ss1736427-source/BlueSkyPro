# SYS-REQ-018 — Mission Memory и Knowledge Engine

## Requirement

Система должна сохранять опыт каждой миссии и использовать его для формирования системных знаний.

олжны учитываться:

- особенности объекта;
- особенности территории;
- погодные условия;
- RF interference;
- расход энергии;
- успешность алгоритмов;
- проблемные зоны;
- ошибки планирования.

акопленный опыт должен использоваться для улучшения следующих миссий.
