# SYS-REQ-033 — риоритет загрузки вычислительного ядра

## Requirement

Система должна обеспечивать оптимальное распределение вычислительных ресурсов ядра с приоритетом функций в соответствии с их критичностью для безопасности и выполнения миссии.

ритические функции  должны иметь гарантированный приоритет вычислительных ресурсов перед второстепенными функциями.

ри дефиците вычислительных ресурсов система должна:

- сохранять работоспособность жизненно важных функций;
- снижать или ограничивать нагрузку второстепенных функций;
- предотвращать перегрузку вычислительного ядра;
- контролировать текущую загрузку ресурсов;
- обеспечивать предсказуемое поведение при пиковых нагрузках.

## Priority

риоритет должен определяться критичностью функции, а не только временем поступления задачи или требуемой производительностью.

## Isolation

агрузка некритичных функций не должна приводить к отказу или недопустимому ухудшению критических функций.

## Verification

олжны проверяться:

- нормальная загрузка;
- пиковая загрузка;
- одновременное выполнение критических и некритических функций;
- отказ/ограничение вычислительных ресурсов;
- сохранение критических функций при перегрузке.
