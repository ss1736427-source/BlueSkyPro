# SYS-REQ-012 — Mission Resilience

## Requirement

Система должна заранее моделировать отказные сценарии и формировать варианты продолжения миссии.

олжны учитываться:

- отказ UAV;
- потеря GNSS;
- потеря C2;
- ухудшение погоды;
- отказ payload;
- снижение батареи;
- потеря relay;
- появление другого воздушного объекта.
