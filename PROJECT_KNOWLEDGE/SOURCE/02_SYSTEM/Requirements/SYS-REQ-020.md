# SYS-REQ-020 — Mission Quality Score

## Requirement

Система должна формировать итоговую оценку качества выполненной миссии и объяснять причины отклонений.

ценка должна учитывать:

- Coverage
- Detection
- Image Quality
- Energy Efficiency
- Response Time

езультат должен использоваться для улучшения следующего плана миссии.
