# SYS-REQ-032 — оддержка разнотипных 

## Requirement

Система должна поддерживать одновременное использование разнотипных  в составе одной миссии.

Система должна обеспечивать:

- регистрацию различных типов ;
- хранение их технических характеристик;
- учёт capabilities каждого типа;
- учёт payload;
- учёт ограничений;
- назначение различных ролей ;
- совместное планирование маршрутов;
- распределение задач между различными типами ;
- координацию их взаимодействия;
- контроль состояния каждого ;
- замену  другим совместимым типом при необходимости.

ыбор типа  должен выполняться исходя из требований миссии, доступных capabilities, payload, ограничений, энергии, связи, безопасности и других параметров миссии.

обавление нового типа  не должно требовать изменения общей архитектуры системы.

## Compatibility

азличные типы  должны взаимодействовать с системой через стандартизированные интерфейсы и контракты.

## Verification

Требование должно проверяться как минимум на виртуальной миссии с двумя или более различными типами .
