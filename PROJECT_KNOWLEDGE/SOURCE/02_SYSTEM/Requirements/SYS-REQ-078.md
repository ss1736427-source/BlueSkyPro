# SYS-REQ-078 — Concurrent Multi-UAV Mission

## Requirement

Система должна обеспечивать одновременное выполнение несколькими  различных частей одной миссии.

 должны иметь возможность выполнять различные роли, включая поиск, подтверждение, наблюдение, ретрансляцию связи и резервирование.

Состояние выполнения задач должно быть доступно Mission Planner через HUB Core.
