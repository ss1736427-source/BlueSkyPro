# SYS-REQ-075 — Heterogeneous UAV Support

## Requirement

Система должна поддерживать одновременное участие в одной миссии  различных типов и конфигураций.

инимально должны поддерживаться различные классы платформ, включая multirotor, fixed-wing и VTOL при наличии соответствующих адаптеров.

Тип конкретной платформы не должен ограничивать общую модель управления миссией.
