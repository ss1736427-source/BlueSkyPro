# SYS-REQ-021 — Mission Economics и Resource-Aware Planning

## Requirement

Система должна оптимизировать эксплуатационные ресурсы при планировании миссии.

олжны учитываться:

- UAV;
- battery cycles;
- flight time;
- charging;
- operators;
- communication;
- cloud compute;
- payload;
- maintenance;
- bandwidth;
- airspace;
- time.
