# SYS-REQ-052 — Интеграция со страховыми провайдерами

## Requirement

Система должна поддерживать интеграцию со страховыми организациями через стандартизированный интерфейс.

Интеграция должна обеспечивать возможность:

- передачи идентификации конкретного INSURED_UAV;
- передачи данных владельца/эксплуатанта;
- передачи параметров операции;
- передачи текущей конфигурации и технического состояния;
- передачи накопленной страховой истории и доказательной базы в пределах разрешенного доступа;
- запроса страхового предложения;
- получения вариантов покрытия;
- получения статуса оформления;
- получения электронных данных полиса;
- проверки действительности полиса;
- передачи результатов предполетной страховой проверки;
- передачи claims-relevant evidence по формализованному запросу.

Конкретный страховой провайдер не должен являться зависимостью ядра BlueSky.

Архитектура:

BlueSky → Insurance Service → Provider Adapter → Insurance Provider.
