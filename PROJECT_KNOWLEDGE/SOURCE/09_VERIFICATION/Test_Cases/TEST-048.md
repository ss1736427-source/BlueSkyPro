# TEST-048 — HUB Graceful Degradation Test

## Objective

Verify [[SYS-REQ-086]] by controlled resource exhaustion and observation of priority-based functional degradation.

## Preconditions

- HUB resource-management mechanism is available.
- Representative P0/P1 functions are available.
- Representative P2, P3, P4 and P5 functions are available.
- Controlled resource load can be generated.
- Function availability and resource utilization can be monitored.

## Test Procedure

1. Start representative P0/P1, P2, P3, P4 and P5 functions under nominal conditions.
2. Record the initial functional state and resource utilization.
3. Gradually increase computational or system-resource load.
4. Verify that P5 functionality is restricted before higher-priority functions.
5. Continue increasing the load.
6. Verify that P4 functionality is restricted before P3 and P2 functionality.
7. If further degradation is required, verify that P3 functionality may be restricted.
8. Verify that P2 functionality remains available to the extent required for safe mission execution.
9. Verify that P0 and P1 functionality remains available in the required scope.
10. Verify that low-priority functions cannot cause loss of required P0/P1 functionality.
11. Record the order and extent of functional degradation.
12. Restore available resources.
13. Verify recovery of previously degraded functions.

## Expected Result

Under resource shortage, functionality degrades according to priority.

P5 and P4 are restricted first.

P3 may be restricted when additional degradation is required.

P2 remains available to the extent required for safe mission execution.

P0 and P1 remain available in the required scope regardless of load generated by lower-priority functions.

## Actual Result

Not executed.

## Result

Not Run

## Evidence Required

- Initial resource utilization.
- Resource exhaustion/load profile.
- P5 degradation record.
- P4 degradation record.
- P3 degradation record, if applicable.
- P2 availability record.
- P0/P1 availability record.
- Final resource utilization.
- Recovery record.
