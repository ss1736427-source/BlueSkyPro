# TEST-001 — Преобразование задачи пользователя в структурированную миссию

## Objective

Проверить преобразование сформулированной пользователем операционной задачи в структурированное представление, пригодное для дальнейшего формирования миссии BlueSky.

## Preconditions

- BlueSky запущен.
- Task Engine доступен.
- Пользователь авторизован и имеет право создать задачу.

## Test Procedure

1. Создать новую задачу пользователя.
2. Ввести описание требуемого результата операции.
3. Передать задачу в обработку.
4. Проверить сформированное структурированное представление задачи.
5. Проверить сохранение исходного запроса пользователя.
6. Проверить связь исходного запроса со структурированным представлением.
7. Передать результат в следующий этап модульного формирования миссии.

## Expected Result

- Задача пользователя принята системой.
- Требуемый результат задачи определён и представлен структурированно.
- Исходный запрос пользователя сохранён.
- Между исходным запросом и структурированным представлением существует трассируемая связь.
- Структурированная задача доступна последующим модулям.
- Система не подменяет пользовательскую задачу заранее фиксированным маршрутом или сценарием.
- Результат может использоваться для дальнейшего модульного формирования миссии.
