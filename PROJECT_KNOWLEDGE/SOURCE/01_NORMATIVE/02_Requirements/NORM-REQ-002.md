# NORM-REQ-002 — Применимость DO-178C

Для программного обеспечения системы планирования должна быть документирована применимость DO-178C, включая границы ПО и применимые процессы разработки, верификации, конфигурационного управления, обеспечения качества и сертификационного взаимодействия.

> Конкретный уровень обеспечения и применимые цели DO-178C пока не определены в исходных данных.
