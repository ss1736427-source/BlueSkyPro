```text
[✓] stable ID

[ ] source / basis

[ ] system allocation

[ ] design allocation
[ ] interface allocation
[ ] verification method
[ ] verification case
[ ] execution result
[ ] evidence
[ ] configuration
[ ] change history
```

`[✓]` above means the control mechanism exists or the specific wording/identity was confirmed; it does not mean the downstream item has been completed for every requirement.

## 15. Rule against false closure

No status such as `FULL`, `COMPLIANT`, `VERIFIED` or `CLOSED` shall be assigned merely because a document, architecture decision, test definition or source register exists.

A relationship is closed only when the referenced record actually exists and is identifiable.
