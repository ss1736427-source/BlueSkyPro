# CAP-001 — Navigation

## Purpose

Provide navigation capability required to determine and maintain the operational trajectory of an aircraft within the approved mission context.

## Description

Navigation shall consume applicable position, motion, mission, spatial and environmental information and produce navigation state required by mission execution.

## Inputs

- position;
- velocity;
- heading;
- altitude;
- mission route;
- waypoints;
- applicable spatial constraints;
- applicable environmental data;
- applicable UAV state.

## Outputs

- navigation state;
- estimated position;
- estimated motion state;
- route-relative state;
- navigation validity.

## Preconditions

- applicable navigation data available;
- required configuration validated;
- applicable mission revision identified;
- required sensors/interfaces available.

## Constraints

- mission constraints;
- spatial constraints;
- temporal constraints;
- UAV capability limits;
- environmental constraints.

## Dependencies

- UAV state;
- telemetry;
- mission configuration;
- map/spatial data;
- applicable environmental data.

## Algorithms

Specific navigation algorithms are intentionally not fixed at architecture level.

Algorithm selection shall be defined during detailed software design and shall remain traceable to this capability.

## Safety Constraints

Navigation shall not silently report valid navigation state when required input integrity or freshness is insufficient.

Safety-critical navigation failures shall be visible to Safety and Readiness mechanisms.

## Interfaces

- Navigation input interface;
- telemetry interface;
- mission state interface;
- spatial data interface;
- environmental data interface;
- execution interface.

## Performance

Performance targets shall be defined during detailed requirements and verification planning.

## Verification

Verification shall demonstrate:

- valid navigation input;
- degraded navigation input;
- stale data;
- invalid data;
- loss of required input;
- route deviation;
- recovery;
- reproducibility where applicable.

## Rationale

Navigation is a reusable system capability and shall remain independent of a particular UAV implementation or navigation algorithm.
