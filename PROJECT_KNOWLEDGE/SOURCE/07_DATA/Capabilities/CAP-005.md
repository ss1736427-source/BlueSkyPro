# CAP-005 — Mapping

## Purpose

Provide spatial representations required for mission planning, navigation, perception and operational awareness.

## Description

Mapping shall ingest and process applicable spatial data and provide a mission-consumable representation.

## Inputs

- map data;
- terrain data;
- sensor observations;
- UAV position;
- environmental data;
- mission context.

## Outputs

- spatial map representation;
- map features;
- terrain representation where applicable;
- spatial validity information.

## Preconditions

- coordinate reference known;
- required spatial data available;
- applicable datasets validated.

## Constraints

- spatial resolution;
- dataset version;
- coverage;
- freshness;
- processing resources.

## Dependencies

- Navigation;
- spatial data;
- terrain;
- external map sources;
- perception where applicable.

## Algorithms

Specific mapping and reconstruction algorithms remain a detailed-design decision.

## Safety Constraints

Spatial data used for safety-critical decisions shall retain source, version and validity context.

## Interfaces

- spatial data interface;
- terrain interface;
- navigation interface;
- perception interface;
- mission interface.

## Verification

Verification shall cover:

- valid map;
- missing coverage;
- stale dataset;
- conflicting datasets;
- coordinate mismatch;
- corrupted data;
- degraded processing.

## Rationale

Mapping is a reusable spatial capability and shall remain independent from a particular map provider or implementation.
