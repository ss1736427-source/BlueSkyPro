# CAP-007 — Search

## Purpose

Provide systematic search of a defined area or volume for mission-relevant objects, persons, conditions or events.

## Description

Search shall generate or execute a search strategy and process observations to determine search coverage and findings.

## Inputs

- search area;
- mission objectives;
- navigation state;
- map/terrain;
- perception;
- detection;
- environmental data.

## Outputs

- search plan;
- coverage state;
- detections;
- search findings;
- unresolved search area.

## Preconditions

- search area defined;
- applicable constraints validated;
- navigation ready;
- required sensing available.

## Constraints

- search geometry;
- terrain;
- airspace;
- geofence;
- weather;
- energy;
- sensor coverage;
- communication.

## Dependencies

- Navigation;
- Mapping;
- Perception;
- Detection;
- environmental data.

## Algorithms

Search-pattern and search-optimization algorithms remain detailed-design decisions.

## Safety Constraints

Search shall remain bounded by approved spatial, temporal, airspace and safety constraints.

## Interfaces

- mission interface;
- navigation interface;
- mapping interface;
- detection interface;
- perception interface;
- execution interface.

## Performance

Coverage and detection objectives shall be defined per mission profile.

## Verification

Verification shall cover:

- complete area;
- partial coverage;
- missed area;
- detection;
- false detection;
- stale data;
- environmental degradation;
- resource exhaustion.

## Rationale

Search is separated from Detection so that search strategy and detection implementation can evolve independently.
