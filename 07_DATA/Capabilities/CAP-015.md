# CAP-015 — Communication Relay

## Purpose

Provide communication relay capability between authorized mission participants and communication domains.

## Description

Communication Relay shall forward authorized communication traffic while preserving identity, integrity, routing context and authority boundaries.

## Inputs

- communication traffic;
- network state;
- relay configuration;
- mission context;
- link state.

## Outputs

- relayed traffic;
- link state;
- connectivity status;
- latency and quality metrics;
- relay health.

## Preconditions

- relay platform available;
- communication interfaces available;
- relay configuration validated;
- authorized communication path established.

## Constraints

- radio/network capability;
- range;
- bandwidth;
- latency;
- power;
- interference;
- security;
- regulatory constraints.

## Dependencies

- Communication;
- C2;
- UAV/Fleet;
- Security;
- Resource Manager;
- Monitoring.

## Algorithms

Routing and link-selection algorithms remain detailed-design decisions.

## Safety Constraints

Communication Relay shall not alter command authority or silently transform unauthorized traffic into authorized commands.

Loss or degradation of relay connectivity shall be observable.

## Interfaces

- communication interface;
- C2 interface;
- network interface;
- telemetry interface;
- monitoring interface;
- security interface.

## Performance

Latency, throughput and availability targets shall be defined by the applicable communication profile.

## Verification

Verification shall cover:

- normal relay;
- link degradation;
- link loss;
- congestion;
- packet duplication;
- packet reordering;
- unauthorized traffic;
- relay failure;
- recovery.

## Rationale

Communication Relay provides network-level mission support without creating a parallel C2 or execution authority.
