# CAP-003 — Detection

## Purpose

Detect mission-relevant objects, features or events from available observations.

## Description

Detection shall identify candidate entities or events and provide structured detection results for downstream capabilities.

## Inputs

- perception data;
- sensor observations;
- mission context;
- detection configuration.

## Outputs

- detection;
- detection location;
- detection attributes;
- validity/confidence information where applicable.

## Preconditions

- required input data available;
- detection configuration validated.

## Constraints

- sensor capability;
- environmental conditions;
- processing resources;
- mission-specific detection criteria.

## Dependencies

- Perception;
- sensor/payload;
- data processing.

## Algorithms

Specific detection algorithms remain a detailed-design decision.

## Safety Constraints

Detection uncertainty shall remain explicit where it affects mission decisions.

## Interfaces

- Perception interface;
- sensor/payload interface;
- mission context interface;
- result interface.

## Verification

Verification shall cover:

- positive detection;
- negative detection;
- false positive;
- false negative;
- degraded sensor data;
- stale data;
- processing failure.

## Rationale

Detection provides a reusable mission capability independent of a particular detection implementation.
