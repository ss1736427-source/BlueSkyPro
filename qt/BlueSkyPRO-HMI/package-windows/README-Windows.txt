BlueSky PRO — Windows verification package

PACKAGE CONTENTS
- appBlueSkyPRO.exe and Qt runtime files (generated by the Windows CI packaging workflow)
- Start-BlueSkyPRO.ps1: asks for a Yandex Maps Tiles API key and starts the app
- Start-BlueSkyPRO-UIOnly.ps1: starts the UI without configuring live MAVLink telemetry

REQUIREMENTS
- Windows 10/11 x64
- Internet access for Yandex map tiles
- A valid Yandex Maps Tiles API key. A MapTiler key is not interchangeable with a Yandex key.

START
1. Extract the entire ZIP archive to a normal writable folder.
2. Open PowerShell in the extracted folder.
3. If script execution is blocked for this process, run:
   Set-ExecutionPolicy -Scope Process Bypass
4. For map verification, run:
   .\Start-BlueSkyPRO.ps1
   Enter a valid Yandex Maps Tiles API key when prompted.
5. For UI-only verification without a key, run:
   .\Start-BlueSkyPRO-UIOnly.ps1

SECURITY
The key is entered at runtime and is not stored in this package or source code. The app needs a Yandex key because the current GoogleMapView.qml requests tiles from tiles.api-maps.yandex.ru.

ALTITUDE TELEMETRY
The altitude service is intentionally unavailable unless every required BLUESKY_* telemetry configuration variable is supplied. Do not invent sensor IDs, UDP ports, or source identities. This package alone does not validate live autopilot telemetry.

LIMITS
This is a verification build, not a signed installer. No hardware-in-loop or real-autopilot verification is claimed.
