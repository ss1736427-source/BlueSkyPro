BlueSky PRO — Windows verification package

PACKAGE CONTENTS
- appBlueSkyPRO.exe and Qt runtime files (generated by the Windows CI packaging workflow)
- Start-BlueSkyPRO.ps1: securely prompts for a MapTiler API key and starts the app
- Start-BlueSkyPRO-UIOnly.ps1: starts the UI without configuring live MAVLink telemetry

REQUIREMENTS
- Windows 10/11 x64
- Internet access for MapTiler map resources
- A valid MapTiler API key with access to the MapTiler styles/tiles used by the application

START
1. Extract the entire ZIP archive to a normal writable folder.
2. Open PowerShell in the extracted folder.
3. If script execution is blocked for this process, run:
   Set-ExecutionPolicy -Scope Process Bypass
4. For map verification, run:
   .\Start-BlueSkyPRO.ps1
   Enter your MapTiler API key when prompted.
5. Alternatively, set the key in the current PowerShell session and launch:
   $env:BLUESKY_MAPTILER_API_KEY = "YOUR_MAPTILER_KEY"
   .\appBlueSkyPRO.exe
6. To inspect the UI without a key, run:
   .\Start-BlueSkyPRO-UIOnly.ps1
   The map will show a MapTiler key-required message.

SECURITY
The key is entered at runtime and is not stored in this package or source code. Do not commit the key to Git.

MAP PROVIDER
MapTiler Hybrid v4 is the only basemap provider in this verification build. Google Maps and Yandex Maps are not used.

ALTITUDE TELEMETRY
The altitude service is intentionally unavailable unless every required BLUESKY_* telemetry configuration variable is supplied. Do not invent sensor IDs, UDP ports, or source identities. This package alone does not validate live autopilot telemetry.

LIMITS
This is a portable verification package, not a signed installer. No hardware-in-loop or real-autopilot verification is claimed.
