# EC-07 Energy / Power

**Status:** IMPLEMENTATION BASELINE
**Source channel:** `SRC-08 ENERGY_POWER`

The baseline defines a common energy/power adapter contract and a prototype adapter for battery telemetry. It preserves source identity and timestamp and validates voltage, current, power, remaining capacity, consumed capacity and estimated remaining time.

The implementation is a prototype/bench mechanism. It does not establish physical battery, power-system, sensor, calibration or flight verification.

## Remaining boundary

EC-07 remains **PARTIAL** until approved real energy/power sources, controlled execution evidence, domain processing/result linkage, integrity-controlled evidence package, certification export verification and physical/operational verification are available.
